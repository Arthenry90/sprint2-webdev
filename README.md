# Sprint 2 - Web Development

## Descricao do projeto
Migração da entrega realizada na sprint 2 - Front-end Design de HTML e CSS para React.  

Desenvolvemos uma plataforma voltada para o gerenciamento de missões e recompensas para o usuário cuidar de sua saúde de uma maneira mais saudável, evitando que o plano de saúde seja acionado apenas em situações críticas ou emergenciais, o que garante mais agilidade no seu atendimento.  

Nesta entrega, a plataforma já tem funcionalidades como verificação de login e resgate de recompensas.  

O projeto ainda está em desenvolvimento, visando a entrega para a Sprint 3 - Care Plus.

## Instruções de Uso

1 - Ao iniciar à pagina, você verá um identificador de login, o que te impede de verificar qualquer pagina da plataforme sem realizar um login.

2 - Após o login, o usuário tem acesso às paginas (Home, Missões, Perfil e Recompensas)
2.1 - Home  
Aqui o usuario pode verificar suas missões não iniciadas, ver a media concluida de suas missões. O usuario não tem ações nesta pagina.

2.2 - Missões  
Usuario pode verificar suas missões pendentes por meio de um array, que futuramente será transformado para json. Nesta entrega o usuário não tem ações, futuramente, iremos adicionar funções para o usuário cocluir missões em aberto, coletar pontos de missões finalizadas e automação para iniciar missões automaticamente após a conclusão de outra.

2.3 - Perfil  
Dentro da pagina de Perfil, o usuário poderá verificar seus dados coletados no cadastro, como: Nome completo, Altura, Peso, Comorbidades ou deficiencias, data de nascimento e foto de perfil (nesta entrega não será possivel alterar a foto de perfil).  

2.4 - Recompensas  
Nesta pagina, temos funcionalidades com LocalStorage, onde o usuário pode resgatar recompensas utilizando seus pontos.
